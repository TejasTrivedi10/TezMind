Neumorphism UI kit

Soft, extruded mobile web components: one base color, paired light and dark shadows, and a single indigo accent. Nunito for headings, Quicksand for text. Everything is interactive and follows light and dark mode.

Foundations

Every surface shares the base color. Depth comes only from shadows.

Accessibility note

Soft shadows alone are low contrast. Keep text at 4.5:1 or better, show a 3px accent focus ring, and never rely on shadow depth to show state.
